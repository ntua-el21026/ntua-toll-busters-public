# Requirements and design evidence

The [original SRS](srs%20-%20softeng24-59.docx) records the team’s coursework
requirements, interface assumptions, and UI designs. The editable
[Visual Paradigm model](softeng24-59.vpp) contains workflow, sequence, class,
component, deployment, and entity–relationship diagrams. Both are evidence
associated with the coursework submission.

For current behavior, see the [project route map](../api/README.md) and
[implementation guide](../backend/README.md). The historical
[structure listing](struct.txt) records earlier deliverable organization. The
[repository overview](../README.md) introduces the current implementation and documentation.
Model inspection requires a compatible edition of [Visual Paradigm](https://www.visual-paradigm.com/).

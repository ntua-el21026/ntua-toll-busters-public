# AI-assisted development record

The retained archives record AI-assisted requirements, architecture, coding,
and testing activities in Team SoftEng24-59’s 2024–2025 coursework. Each
archive organizes questionnaire or session metadata with the associated
dialogue where available. The [project overview](../README.md) describes
the implementation and validation results. The [NTUA AI log tool](https://ailog.softlab.ntua.gr/)
was used to record and submit sessions during the course.

Two supplied course passages are represented by original paraphrases in
the retained transcript, as described below. Exact dialogue reproduction
would require authorized access to the original team submission and the
corresponding course requirements.

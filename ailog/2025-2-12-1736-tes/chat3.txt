# Toll System CLI Application

This project provides a command-line interface (CLI) to interact with a toll system backend. It allows administrative operations such as checking system health, resetting toll passes and stations, managing users, and more.

## Overview

The CLI application is built with Node.js using the [Commander](https://www.npmjs.com/package/commander) library. It uses [Axios](https://www.npmjs.com/package/axios) for HTTP requests to communicate with the backend API. The tool supports user authentication (login/logout), system health checks, resets, user administration, pass analysis, invoice operations, and more.

Troubleshooting
TLS Certificate Warning:
The CLI disables TLS certificate verification (by setting NODE_TLS_REJECT_UNAUTHORIZED=0), so you will see warnings about insecure TLS connections. This is intended for development purposes only.

Missing Token Error:
If you see errors indicating that the authentication token is missing, ensure that you run the login command before executing other commands.

File Not Found Errors:
Verify that paths (such as the CSV file for adding passes) are correct relative to the CLI directory.
